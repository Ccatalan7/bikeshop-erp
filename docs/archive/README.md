# Documentation Archive

This directory preserves dated implementation handoffs and incident context for
provenance. Archived documents are not current operating instructions. Before
following a command or schema recommendation from an archived document, verify
it against `AGENTS.md`, `.github/copilot-instructions.md`, the applicable living
architecture document, and the current code/schema.

## Index

- `2026-01/`: website editor refactor handoff.
- `2026-02/`: historical Smart Tasks remaining-work handoff.
- `2026-03/`: accounting incident, supplier portal, and WhatsApp Cloud API handoffs.
- `2026-04/`: workshop timeline, inventory movements, consumables, and egress handoffs.
- `2026-05/`: online orders and internal messaging handoff.
- `2026-06/`: WhatsApp catalog and commerce handoff.

Living setup, testing, release, security, and architecture documentation belongs
under `docs/development`, `docs/guides`, `docs/runbooks`, or
`docs/architecture`, not in this archive.
