# schema.org `[SO]`

`schema.org`. Define los tipos y propiedades; Google decide cuáles usa
([google-search-central](google-search-central.md)).

## Consultado el 2026-10-03

| Página | Qué se tomó |
|---|---|
| `schema.org/BikeStore` | existe: Thing → Organization/Place → LocalBusiness → Store → **BikeStore** («a bike store») |

## Cómo leerla

- Que schema.org tenga una propiedad no significa que Google la use; para
  resultados enriquecidos manda la página de Google del tipo.
